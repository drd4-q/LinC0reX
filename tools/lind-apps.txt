# Приложения для lind.
#
# По одной строке на приложение:
#
#   Имя | команда | цвет
#
# Имя — подпись под плиткой, команда — что запустить в chroot, цвет — фон
# плитки (0xAARRGGBB). Строки, начинающиеся с #, игнорируются.
#
# Файл перечитывается при запуске композитора, так что менять можно прямо на
# телефоне: /data/lindroid/droot/usr/share/lindroid/apps
#
# Здесь нет .desktop-записей: регистрироваться им некуда, в chroot нет
# рабочего окружения. Поэтому список и есть файл.
